# Design Builder option pictures: 33 prompts

Real photos for the option cards in **Create Your Own Design**, replacing the line drawings. Embroidery is left out for now.

Checked against the live designer on 30 Oct 2026: Neck Type 9, Sleeve Type 8, Length 5, Lower 6, Dupatta 5. Every garment shares one picture per option (a Round Neck is the same picture on the Kurti and the Anarkali), so each option needs only one image. Fabric, Colour and Size need no new pictures.

## How to use

1. **Style first.** Generate *Neck Type → Round Neck* first. Keep that image and attach it to every next prompt as the reference, starting the message with: *"Same mannequin, background, lighting, camera and kurta colour as the attached image. Only change:"*. Then paste the prompt. All 33 cards then look like one set.
2. **One prompt = one image.** Figma, Gemini and ChatGPT tend to merge a long list into a single collage, so paste the prompts one at a time. Make 2–3 versions and keep the one where the feature is clearest.
3. **Size:** landscape 4:3, at least 1200 × 900. JPG.
4. **File name:** the one shown above each prompt (e.g. `neck-round-neck.jpg`).
5. **Upload:** Shopify admin → **Content → Metaobjects → Design Image**. Open the entry with the **key** shown (e.g. `option/neck/round-neck`), add or replace the picture and save. The website picks it up within a few minutes.

## Back view of the neck: not needed

Each option card shows one picture, and the AI preview takes one reference per option, so a back-neck picture would not appear anywhere. Use the front view only.

If you later want back-neck styles (deep back, back keyhole, tie-up…), that would be a new option group in the designer, and its pictures would be back views.
